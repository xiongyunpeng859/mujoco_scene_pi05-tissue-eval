# 到绿色盒子上方直接释放（当前动作版本）

按用户最新要求，取消放置前的垂直下放动作。

动作顺序：接近纸巾袋 → 下降抓取 → 闭合 → 抬起 → 搬到盒子上方 → 原位张手 → 撤离。
这里保留的“下降”只用于桌面抓取；放置阶段没有下放段。

对中补偿在搬运过程中平滑完成。张手期间保持搬运结束时的六轴关节指令不变，只改变手部开合。`--release-dz` 若使用，统一作用于搬运/释放高度，不引入额外下降段。

验收改为搬运末帧仍持有袋子、搬运全程连续接触；放开后零手部接触、完整落盒并稳定至少 0.5 秒。原运动质量判据和落盒容差不变。
